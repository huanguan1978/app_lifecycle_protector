# App Lifecycle Protector Example App

Run the example app from this directory:

```shell
flutter run
```

The app demonstrates the lifecycle framework, screen protection, and network
probing. The screen starts locked; use the alternate method and enter `123456`
to unlock.

For the guide shown in pub.dev's **Example** tab—including the source layout,
platform network configuration, and proxy setup—see [`example.md`](example.md).
